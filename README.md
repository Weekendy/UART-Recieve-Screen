# UART_Show_F103C8T6

这是一个基于 STM32F103C8T6 的串口数据显示屏，可显示原始串口数据或自定义协议解析结果。通过 USART1 接收数据，在 ST7735 TFT 屏幕上显示解析后的数值或原始十六进制字节；可使用板载按键切换显示模式和设置串口波特率。

## 功能

- 通过 USART1 接收数据，默认波特率为 115200，格式为 8N1。
- 使用 DMA 和环形缓冲区接收数据。
- 解析带 `AA 55` 帧头和累加和校验的 YF 数据帧，并显示命令字及其数据。
- 提供原始数据模式，按十六进制显示接收到的字节。
- 支持按键暂停/继续显示、切换模式和进入波特率菜单。
- 使用 STM32 HAL，配置文件由 STM32CubeMX 工程 `UART_Show_F103C8T6.ioc` 管理。

## 硬件连接

工程目标芯片为 STM32F103C8T6，屏幕及串口引脚配置如下。连接串口设备时请交叉连接 TX/RX，并共地。

| 信号 | MCU 引脚 | 用途 |
| --- | --- | --- |
| USART1_TX | PA9 | 串口发送 |
| USART1_RX | PA10 | 串口接收 |
| SPI1_SCK | PA5 | ST7735 时钟 |
| SPI1_MOSI | PA7 | ST7735 数据 |
| CS | PA0 | 屏幕片选 |
| DC | PA1 | 屏幕数据/命令选择 |
| RST | PA2 | 屏幕复位 |
| BL | PC13 | 屏幕背光 |
| Key1 | PB3 | 按键 1，输入上拉 |
| Key2 | PB4 | 按键 2，输入上拉 |

ST7735 模块的电源和接口电平应符合所用屏幕模块及开发板的要求。

## 串口帧格式

解析模式下，一帧由帧头、数据项数量、命令、带类型的数据项和校验和组成：

```text
AA 55 LEN CMD [TYPE DATA]... CHECKSUM
```

- `LEN`：数据项数量，不包括命令字节。
- `CMD`：命令字节。
- `TYPE`：数据类型标识，后接对应长度的数据。
- `CHECKSUM`：从 `LEN` 到最后一个数据字节（含）的 8 位累加和。

| TYPE | 数据类型 | 数据长度 |
| --- | --- | --- |
| `00` | 无符号 8 位整数 | 1 字节 |
| `01` | 有符号 8 位整数 | 1 字节 |
| `02` | 无符号 16 位整数 | 2 字节 |
| `03` | 有符号 16 位整数 | 2 字节 |
| `04` | 无符号 32 位整数 | 4 字节 |
| `05` | 有符号 32 位整数 | 4 字节 |
| `06` | IEEE 754 单精度浮点数 | 4 字节 |

多字节数值按高字节在前发送。接收端逐字节累加校验和，溢出时保留低 8 位。`LEN` 最大为 64。原始数据模式不要求发送方遵循此帧格式。

## 按键操作

短按定义为按下后释放；长按时间为 500 ms。

| 操作 | 功能 |
| --- | --- |
| Key1 短按 | 暂停显示；暂停时短按继续并清空当前显示/接收状态 |
| Key1 长按 | 在解析模式和原始数据模式间切换 |
| Key2 长按 | 进入设置菜单；再次长按退出 |
| 菜单中 Key1 短按 | 上一项 |
| 菜单中 Key2 短按 | 下一项 |
| 菜单中 Key1 长按 | 确认/进入 |
| 菜单中 Key2 长按 | 退出菜单 |

菜单提供以下波特率：9600、19200、38400、57600、74880、115200、230400、460800、921600、1000000。

## 构建与下载

使用 Keil MDK-ARM 打开 `MDK-ARM/UART_Show_F103C8T6.uvprojx`，选择目标后执行 Build，再使用 ST-Link 或兼容的 SWD 调试器下载。工程芯片配置为 STM32F103C8（Cortex-M3）。也可使用 STM32CubeMX 打开根目录下的 `.ioc` 文件查看外设配置。

## 目录结构

```text
APP/       显示控制、菜单、设置与数据处理
BSP/       ST7735、数据帧、环形缓冲区、按键及日志驱动
Core/      STM32 HAL 初始化、主程序和中断处理
Drivers/   STM32F1 HAL 与 CMSIS 库
MDK-ARM/   Keil MDK-ARM 工程
*.ioc      STM32CubeMX 配置
```

## 排查提示

- 屏幕无显示：检查 ST7735 接线、电源、背光和屏幕模块的控制器/尺寸兼容性。
- 没有串口数据：检查 PA9/PA10 交叉连接、共地、波特率和 8N1 设置。
- 解析模式没有数据显示：确认发送端使用 `AA 55` 帧头、有效类型值和正确的累加校验和；可切换到原始数据模式检查收到的字节。
- 修改引脚或时钟后：同步更新 CubeMX `.ioc` 配置与 BSP 中的屏幕配置，并重新构建。
